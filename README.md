## Frugy 
Este proyecto robot triatlón fue creado con la intencion de competir en las Bonaerenses 21/08/2025, en las categorias Sumo RC, Despeja Area y Velocista. Que fue llevado por los alumnos de 5°6 Ulises Basabe, Facundo Dominguez, Gonzalo Flores y Ramiro Trejo. A lo largo de varias pruebas realizadas por los mismos 

**Todo este proyecto pudo funcionar gracias a los programas de Arduino Ide para su desarollo de software, KiCad 9.0 para su desarrollo de PCBs, y por ultimo Fusion 360 para su diseño 3D**
