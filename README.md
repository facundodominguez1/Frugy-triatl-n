## Frugy 
Este proyecto robot triatlón fue creado con la intencion de competir en las Bonaerenses 21/08/2025. Que fue llevado por los alumnos de 5°6 Ulises Basabe, Facundo Dominguez, Gonzalo Flores y Ramiro Trejo. A lo largo de varias pruebas realizadas por los mismos.


**Todo este proyecto pudo funcionar gracias a los programas de Arduino Ide para su desarollo de software, KiCad 9.0 para su desarrollo de PCBs, y por ultimo Fusion 360 para su diseño 3D**


## SUMO RC
Esta categoría llamada Sumo RC (Radio Controlado), se basa en quitar del tatami al rival, el cual una persona está encargada de maniobrar al robot.

## VELOCISTA
Por este lado el robot tiene como objetivo completar una pista de carreas de la manera mas rápida y precisa posible, que en esta pista se pueden llegar a incluir obstaculos para dificultar la vuelta

## DESPEJA AREA
Esta rama es cuando el robot tiene que sacar una serie de cubos de una pista de la manera mas eficiente, obteniendo así dsitintos puntajes sin este poder salir de la misma
